# Glossary

## Caretaker skill

A skill that owns one mutable artifact end to end — read the whole thing before editing,
propose the exact change, write only after confirmation, report changed lines only — rather
than producing that artifact as a byproduct of some other task.

_Avoid_: none.

## Dogfooding

This repo applying one of its own documented conventions to its own reference material, not
only prescribing it for consuming repos.

_Avoid_: none.

## Drift

A durable doc's content silently diverging from what the process or codebase it describes has
become, so agents and humans keep working from an inaccurate document without noticing.

_Avoid_: none.
